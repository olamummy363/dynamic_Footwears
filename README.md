# Shoe Making Business Website

## Project Description

This project is a website designed for a shoe making business that showcases footwear products and provides customers with information about the business, its products, and its services.

The website is designed to give the visitors a simple and convenient way to learn about the brand, and understand the ordering and delivery process.

## Project Specifications

The website includes the following PAGES, SECTIONS and FEATURES:

- **Home Page:** Introduces the business and gives visitors an overview of the website.
    Under this page we have sections as follows: header, products section, occasions section, types of shoe section, testimonial section, CTA section and  Footer section.

- **About Us:** Provides information about the business, its mission, vision, craftsmanship, and commitment to quality.
    Under this page we have sections as follows: sub-header, about, about-addition, process-section and footer.

- **Products/Gallery:** Displays the shoes available and allows visitors to view the products.
    Under this page we have sections as follows: sub-header, product-section, types-section and footer.

- **Blog Section:** Provides useful information and articles related to footwear, shoe care, styling, and craftsmanship.
    Under this page we have sections as follows:sub-header, blog section and footer.

- **Contact/Booking Section:** Provides a way for customers to contact the business or make enquiries.
    Under this page we have sections as follows:sub-header, location-section, contact-section and footer

## Tools and Technologies Used

The following tools and technologies were used during the development of the website:

- **HTML5:** Used to structure the content and different sections of the website.
- **CSS3:** Used to style the website, including colours, spacing, layouts, and responsiveness.
- **JavaScript:** Used to add interactive functionality to the website.
- **Bootstrap 5:** Used for styling and responsive design components, where applicable. 
- **Bootstrap Icons:** Used to add icons to different sections of the website, where applicable.
- **Visual Studio Code:** Used as the code editor during development.
- **Git:** Used for version control.
- **GitHub:** Used to store and manage the project's source code.
- **netlify** will also be used to deploy

## Project Objective

The main objective of this project is to develop a website that improves the online presence of a shoe-making business, showcases its products, and makes it easier for potential customers to access information about its products and services.

## Project Structure

The project files are organised into the following main categories:

- **HTML files:** Contain the structure and content of the website and also the JAVASCRIPT codes.
- **CSS files:** Contain the styling and layout of the website.
- **Images folder:** Contains the images and visual assets used on the website.

## Conclusion

This project demonstrates the use of web development technologies to create a website for a shoe-making business. It combines website structure, styling, and interactive functionality to provide visitors with an organised and user-friendly experience.
